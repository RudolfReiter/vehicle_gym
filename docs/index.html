How to read the ghost. At 0, 3, 6… seconds, the orange path freezes the planner’s next three seconds. The ghost then moves along that frozen path at the same elapsed time as the blue car. A gap shows how the executed drive diverged as the controller replanned. At the next boundary, a new forecast begins from the current state. This measures plan consistency under replanning, not an independent learned prediction model.

Research contribution · ECC 2023

A Hierarchical Approach for Strategic Motion Planning in Autonomous Racing

The research separates high-level strategic choices from low-level motion planning. vehicle_gym provides the dynamics and planner interface. Its new portable backend makes this separation runnable without compiling acados; the original acados implementation remains in the repository.

Repository improvements

  • Lazy optional imports and complete package discovery, including track resources.
  • Independent planning snapshots, full reference-shape validation, and separating-axis rectangle collision checks.
  • Examples separated from regression tests; corrected module names retain compatibility imports.

Differences from the paper

  • CasADi/IPOPT replaces the original acados/HPIPM solver in these runs.
  • Opponents use lane tracking and car following; the ego predicts constant opponent speed and lateral position.
  • Obstacle ellipses are expressed in Frenet coordinates with bounded slack (0–0.08). Collision checks approximate bodies in Frenet coordinates.
  • No recursive-feasibility terminal set or safety guarantee. Synthetic circuit sections and short episodes replace the paper’s larger benchmark.

Car example evaluation

Three references · three tasks · one fixed seed

Nine recorded simulations compare center, left, and right references in overtaking, blocking, and mixed traffic. Every trajectory below comes from the nonlinear planner and the original five-state vehicle model.

All nine runs use seed 101 and a 16-second episode limit. This is a deterministic demonstration of the interface, not a statistical benchmark. Collisions use an axis-aligned Frenet body approximation sampled every 0.05 seconds.

Numerical setup and provenance

Python 3.9 · NumPy 1.26.4 · SciPy 1.13.1 · CasADi 3.8.1 / IPOPT. The planner uses 12 intervals of 0.25 s, a five-state Frenet model, RK4 integration, and three opponents. Simulation uses five substeps per interval. Full settings, checkpoint provenance, and limitations are documented in the repository.

What is included in the repositories?

Python source, regression tests, recorded evaluations, editable web visualization, a scientific figure generator, citation metadata, and GitHub Pages deployment. The original acados planner and demonstration scripts remain available as an optional legacy stack.
