The original package omitted nested modules and data, imported optional backends eagerly, and shared planning-result state across calls. This change fixes those issues, makes reference validation fail explicitly, and detects crossing-rectangle collisions. Existing acados APIs remain available, with import shims for corrected module spellings.

A new portable CasADi/IPOPT planner reuses the original Frenet model and provides seeded multi-car simulations for the separate HILEPP policy wrapper. The white ECC 2023 research page replays actual simulations with a smooth camera, fixed forecast ghosts, plots, and raw data downloads. Original examples and media are preserved in dedicated folders.

Validation: portable numerical/regression tests, isolated wheel imports and track resources, a real IPOPT solve outside the source checkout, Ruff checks for new modules, playback-state tests, and exported-data/site checks. Nine recorded driving runs complete without detected collisions or solver failures. Full legacy acados integration and browser layout have not been verified. This backend omits the paper’s terminal invariant set and uses simplified opponents and collision geometry; it makes no safety guarantee.
